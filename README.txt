OLAVI SIVHUTE KANGUMBE COMBINED SCHOOL WEBSITE
=================================================

This is a starter website for the school.

HOW TO VIEW IT
1. Open index.html in a web browser.
2. The website works on phones, tablets and computers.

HOW TO CUSTOMISE IT
- Replace images/school-hero.jpg with a real school photograph.
- Replace the "School Photo", "Learners", etc. gallery placeholders with real photos.
- Add the school's telephone number.
- Update the admissions dates and grades when necessary.
- Replace the OSK logo placeholder with the official school logo.

BEFORE PUBLISHING
Connect the contact form to a form service or school email system.
Then publish the files through a web host such as GitHub Pages, Netlify, or another hosting provider.
